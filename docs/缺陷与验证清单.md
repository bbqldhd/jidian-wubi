# 缺陷清单与验证场景清单

## 1. 旧版遗留缺陷清单（逐项修复方案）

| # | 缺陷 | 修复方案 | 状态 |
|---|---|---|---|
| D1 | IMM32 输入法在现代应用（UWP/Edge/新版 Office）不可用 | 整体迁移 TSF（`ITfTextInputProcessorEx` + 候选 UI 元素） | ✅ 已实现（`src/win/tsf/`） |
| D2 | 高 DPI 候选窗/状态栏模糊错位 | 候选走系统 `ITfCandidateListUIElement`；经典皮肤窗口用 Direct2D + Per-Monitor-V2 manifest | ✅ 框架已就位（manifest 已含 DPI） |
| D3 | 32/64 位双套 .ime 配置不同步 | 单配置源 `%APPDATA%\FreeIME11`，DLL 内无跨进程全局状态 | ✅ 已实现 |
| D4 | 词库写系统目录需管理员、UAC 下造词静默失败 | 用户数据目录化（`userFreewbPath()` 补丁） | ✅ 已实现 |
| D5 | 私有二进制词库损坏无恢复 | 系统词库改用 FreeWB 文本化码表；用户词库 `user_word.txt` 文本 + 迁移器 | ✅ 已实现 |
| D6 | 无签名被 SmartScreen 拦截 | 全量 Authenticode（EV）签名 | ⚠️ 需签名证书（发布环节） |
| D7 | 手工写 `Keyboard Layouts` 注册、卸载残留 | TSF 标准注册/注销（`ITfInputProcessorProfiles`） | ✅ 已实现（`dllmain.cpp`） |
| D8 | 多线程宿主偶发崩溃〔待确认〕 | TSF 单线程 apartment 语义 + WER 崩溃转储 | ⚠️ 需真机压测确认 |
| D9 | 远程桌面/安全桌面交互异常〔待确认〕 | TSF 由系统管理安全桌面行为 | ⚠️ 需真机验证 |

## 2. 需要验证的关键使用场景清单

1. Win11 26H2 **x64** 与 **ARM64** 全新安装后，语言和区域中出现「极点五笔 11」。
2. 记事本、资源管理器地址栏、Edge/Chrome、Office、Windows 终端、VS Code、QQ/微信中输入与候选跟随。
3. 锁屏/登录界面、UAC 安全桌面、远程桌面会话、多用户快速切换（Fast User Switching）。
4. 全快捷键回归：右 Shift 中英文切换、`;`/`'` 选二三重码、`-`/`=` 翻页、空格/数字选字、Ctrl 系列（反查/加词/删词/字符集切换/引擎切换）、简入繁出、全半角、软键盘。
5. 五笔/五笔拼音/拼音/英文四引擎切换与各自编码行为。
6. 自动造词、在线加词（Ctrl+=）、删词（Ctrl+-）、调频跨重启持久化。
7. 中文标点映射、智能标点配对、数字后自动半角、标点顶字上屏。
8. 皮肤切换、高 DPI（150%/200%/双屏异 DPI）、深色模式、输入法指示器。
9. **10.8.9 → 11.0.0 配置迁移完整性比对**（`freeime11-migrate` 输出 vs 原 default.ini）。
10. 卸载与重装：无残留注册项、保留用户词库、再次安装正常。
11. 与微软拼音/搜狗等第三方输入法并存切换。
12. 8 小时打字压测（句柄/内存泄漏）与崩溃恢复。

## 3. 编译验证状态

- 本机无 MSVC / Windows SDK，**TSF 前端无法在本机编译**；需在 Visual Studio 2022/2026（含 C++ 工具链与 Windows SDK）中构建验证。
- 可移植层（`engine/` + `utils/` + `session/`）本拟用 MinGW 独立编译 + `ctest` 验证，因本机无现成编译器、从国内镜像安装工具链耗时过长，**本次未完成本地编译**。构建步骤见 README，需在具备工具链的环境执行。
- 已在静态层面核对：引擎类名/接口（`WbzxEngine/Wbpy/PyEngine/En`、`putKey/getResult/reset`）、配置键名（`chinesePunc/fullWidthFlg/simpTradFlg/candiWordCount/secondRecodeKey/…`）与 vendored 源码一致。
