# 逆向分析报告：极点五笔 10.8.9 → FreeIME 11

## 1. 目标与证据

分析对象：`setup10.8.9.exe`（7,426,056 字节，NSIS 打包，LZMA solid，62 个文件，解压后约 22.3 MB）。

| 结论 | 证据（观察） |
|---|---|
| 产品 = 极点五笔 纪念版，安装包 10.8.9，IME 版本资源 7.1.5.0 | PE 版本资源 `FileDescription="极点五笔 纪念版"` |
| 输入框架 = **纯 IMM32** | `freeime.ime` 导出 `ImeInquire/ImeProcessKey/ImeToAsciiEx/ImeConfigure/NotifyIME/ImeRegisterWord/ImeConversionList/ImeDestroy/…`；无 `ITfTextInputProcessor`、不链接 `msctf.dll` |
| 双架构 | 同时携带 32 位（freeime.ime/dll）与 64 位（freeime64.ime/dll） |
| 注册方式 = 旧式键盘布局 | `registry.exe` 导入 `LoadKeyboardLayoutW / ActivateKeyboardLayout / ImmGetIMEFileNameW / RegCreateKeyExW` |
| 配置 = GBK INI | `freeime.ini`（入口，指向方案）→ `default.ini`（约 90 项，[System]/[QuickKey]/[软键盘]） |
| 标点自定义 = symbol.txt（一对一映射，`!=！` 等） | 文本文件 |
| 快速码表 = quick.txt（1 位码 = 词条） | 文本文件 |
| 词典 = 私有二进制 | `freeime.mb` 头 `Freeime Dictionary V6.3`；`attach.mb` 头 `V6.0`；`freeime.dat`/`freeime.tab` 为索引/字型表 |
| 插件 = DLL 伪装 .plg | `command.plg`（命令直通车）、`query6.plg`（编码反查）、`tooltip.dll`（候选窗鼠标查词典） |
| 词典查询库 | `极点汉语词典.db`（7,853,056 字节），与 FreeWB 仓库 `data/dict/freeime_chinese_dict.db` **SHA-256 完全一致** → 同源 |

## 2. 与原版 10.8.9 对应的功能模块

见 `实现说明.md` §2。核心可感知行为（按键、候选、配置项、用户词典）已逐条提取并映射到 FreeIME 11 的会话层与配置键。

## 3. 旧版遗留缺陷（静态证据 + 公认历史问题）

| # | 缺陷 | 后果 | 重制方案 |
|---|---|---|---|
| D1 | IMM32 无 TSF 接口 | Win8/10/11 现代应用（UWP/Edge/新版 Office）不可用 | 整体迁移 TSF |
| D2 | GDI 位图皮肤，无 DPI 感知 | 高 DPI 模糊/错位 | Direct2D + Per-Monitor-V2 |
| D3 | 32/64 位双套 .ime，配置不同步 | 设置不一致 | 单配置源 `%APPDATA%\FreeIME11` |
| D4 | 词库写系统目录需管理员 | UAC 下造词静默失败 | 用户数据目录化 |
| D5 | 私有二进制词库无恢复手段 | 损坏即丢 | 用户词库 SQLite + 迁移器 |
| D6 | 无 Authenticode 签名 | SmartScreen/杀软拦截 | EV 签名 |
| D7 | 手工写 `Keyboard Layouts` 注册 | 卸载残留、语言栏异常 | TSF 标准注册/注销 |

（D6 之外的多线程崩溃、远程桌面交互异常等为同类 IMM 输入法通病，属〔待真机确认〕项。）

## 4. 开源代码库交叉验证

2022 年原作者授权 openKylin 开源 FreeWB（Mulan PSL v2.0）。其 `src/engine`（五笔/拼音/五笔拼音/英文引擎，
UTF-8 字符串接口，`putKey(prefix)/getResult()`）与 `src/utils`（`settings` 配置注册表，含 `cnEnSwitch/secondRecodeKey/thirdRecodeKey/prevPageKey/nextPageKey/chinesePunc/simpTradFlg/autoPhrase/autoAdjustFreq` 等与 10.8.9 一一对应的键）即为本重制的引擎与配置蓝本。词典查询库字节级一致，进一步证明同源。

> 上游无 Windows/TSF 前端（仅 fcitx4/5、ibus），故 TSF 前端、会话层、迁移工具为本项目**新增**。
