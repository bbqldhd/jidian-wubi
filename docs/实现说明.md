# FreeIME 11 实现说明

## 1. 架构变更要点（IMM32 → TSF）

1. **输入处理链路**：由「系统调用 `.ime` 导出函数」变为「TSF manager 向 in-proc COM 文本服务推送 key event」。
   - `FreeIME11Service` 实现 `ITfTextInputProcessorEx`（激活/反激活）、`ITfKeyEventSink`（按键路由到 Session）、
     `ITfThreadMgrEventSink`（焦点/文档切换）、`ITfEditSession`（组合与上屏）、`ITfCompositionSink`（组合终止）、
     `ITfUIElementSink`（候选 UI）。
   - 候选用 `ITfCandidateListUIElement`（系统外壳统一渲染 → 自动获得输入法指示器、深色主题、触摸键盘、DPI 支持）。
2. **会话层解耦**：新增跨平台 `session/`（`Session` 状态机 + `SessionOutcome` 结果），
   复刻 10.8.9 的状态语义（空闲 / 组合 / 临时英文 / 临时拼音 / 在线造词 / 在线删词），
   与 TSF 前端通过纯数据结构交互 → 可在无 Windows SDK 环境下用 MinGW 独立编译与单测。
3. **引擎复用**：vendor FreeWB 的 `engine/`（`WbzxEngine/Wbpy/PyEngine/En`），
   其 `putKey(prefix) → CandidatePayload` 接口与 10.8.9 的「前缀检索候选」一致。
4. **配置模型**：沿用 FreeWB `settings` 的配置项注册表（键名与 10.8.9 语义对应），
   新增 `legacy_importer` 把旧版 GBK INI 迁移为 UTF-8 `config.ini`。
5. **数据路径**：`utils::userFreewbPath()` 补丁为 Windows `%APPDATA%\FreeIME11`（可 `FREEWB_DATA_DIR` 覆盖）。

## 2. 必须保留的核心行为（已实现于 session 层）

- 五笔/五笔拼音/拼音/英文四引擎循环切换；中英文切换（右 Shift，默认）。
- 编码输入 → 候选分页（页大小可配）；数字/空格选字、`;`/`'` 选二三重码；`-`/`=` 翻页。
- 2 码唯一 / 满 4 码唯一自动上屏；回车清空编码（`EnterFunction`）。
- 中文标点映射（对齐 symbol.txt 默认）、智能标点、数字后自动半角、标点顶字上屏。
- 临时英文（`AutoEnStr` 前缀）、临时拼音（z 引导）、临时生僻字（` 引导，GBK）。
- 命令直通车（`;` 引导）、简入繁出（`simpTradFlg`）、全半角、在线造词/删词/调频。

## 3. 兼容性适配措施

- **架构**：x64 / ARM64 双原生；DLL 内零跨进程全局可变状态、每线程 `ITfThreadMgr` 正确聚合，兼容 UWP/打包进程。
- **注册模型**：系统级（MSI 管理员安装）写 `HKLM\SOFTWARE\Microsoft\CTF\TIP\{CLSID}\LanguageProfile` + `ITfInputProcessorProfiles::Register/AddLanguageProfile`；
  能力位注册 `UIELEMENTENABLED`/`SYSTRAYSUPPORT`；运行期零提权。
- **旧版 API 替换**：`LoadKeyboardLayout` 注册器（registry.exe）废弃；GDI 皮肤 → D2D；ANSI/GBK → Unicode/UTF-8；
  `SetWindowsHookEx` 等全部移除（TSF key sink 覆盖）；未使用任何第三方不安全组件（sqlite 为可选，默认上游文本回退）。
- **构建**：C++20、MSVC v143+、CMake；`/GUARD:CF /CETCOMPAT /HIGHENTROPYVA /NXCOMPAT /DYNAMICBASE`；Authenticode 签名。
- **版本**：11.0.0.0（版本资源、manifest、MSI ProductVersion 同步）。新 CLSID/Profile GUID，可与旧版并存灰度。

## 4. 构建与产物

- `FreeIME11.dll`（TSF 文本服务，x64/ARM64）+ `freeime11-migrate.exe` + `freeime11-settings.exe`。
- `installer/FreeIME11.wxs`（WiX MSI）执行 `DllRegisterServer` 与迁移。
- 可移植层可用 MinGW 独立编译 + `ctest`（见 README）。

## 5. 需要验证的关键使用场景

1. Win11 26H2 x64/ARM64 全新安装后语言栏出现「极点五笔 11」。
2. 记事本/资源管理器/Edge/Office/终端/VS Code/QQ 微信 中输入与候选跟随。
3. 锁屏/UAC 安全桌面/远程桌面/多用户快速切换。
4. 全快捷键回归（§2 全表）+ 三引擎切换 + 简入繁出/全半角/软键盘。
5. 自动造词/在线加删词/调频跨重启持久化。
6. 高 DPI（150/200% 双屏异 DPI）与深色模式。
7. 10.8.9 → 11.0.0 配置迁移完整性比对；卸载无残留；与微软拼音等第三方输入法并存切换。
8. 8 小时打字压测（句柄/内存泄漏）与崩溃恢复。
