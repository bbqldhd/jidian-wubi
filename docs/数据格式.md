# 数据格式说明

## 1. 旧版（10.8.9）数据文件

| 文件 | 大小 | 格式 | 说明 |
|---|---|---|---|
| `conf/freeime.ini` | 164 B | GBK INI | 入口：`[System] ConfigFile=jidian.ini` 指定方案 |
| `conf/default.ini` / `jidian.ini` | ~7.3 KB | GBK INI | 方案配置：`[System]`（~90 项）、`[QuickKey]`（快捷键）、`[软键盘]` |
| `symbol.txt` | 748 B | 文本 | 标点一对一映射：`!=！` |
| `mb/default/quick.txt` | 208 B | 文本 | 快速码表：`s=……` |
| `mb/default/freeime.mb` | 1,438,093 B | 二进制 `Freeime Dictionary V6.3` | 主五笔码表（编码→词条） |
| `mb/default/attach.mb` | 4,663,774 B | 二进制 `Freeime Dictionary V6.0` | 挂接词库 |
| `mb/default/freeime.dat` | 84,012 B | 乱序 ASCII（疑似加密/索引） | 字型表 |
| `freeime.tab` | 30,679 B | UTF-16LE 索引 | 字符→编码辅助表 |
| `plugin/data/极点汉语词典.db` | 7,853,056 B | 与 FreeWB 同源 | 汉语词典查询库 |

### 1.1 freeime.mb 结构（已探明部分）

- 头：`"Freeime Dictionary V6.3"` + 混合编码描述（GBK "常用字词库及自动…" + UTF-16LE "3 版 for 极点五笔 Unicode 版本 / 生成日期:2011-12-27…"）。
- 保留区（填充 0）。
- 字母表：`0x1B` 长度前缀 + 27 个 UTF-16LE 字符 `abcdefghijklmnopqrstuvwxyz/z`。
- 码长模式串（UTF-16LE）：`p11+p21+p31+p32/`。
- 哨兵 `zz` + 27 项递增 u32 偏移索引（指向各首字母分块的记录区）。
- 记录区：变长编码 `[码长][编码 ASCII][词条 GBK]`（记录边界规则未完全确定，见下文）。

> ⚠️ 记录区边界规则尚未 100% 确定。重制版不运行时读取旧 .mb，而是：(a) 系统词库改用 FreeWB 已转换的
> `data/mb/default/{wbzx.mb,pinyin.mb}`（同源、UTF-8 文本化、Mulan 许可）；(b) 用户自造词若需从 10.8.9 迁移，
> 走 `freeime11-migrate` 的「旧 .mb → 文本」离线转换器（待记录边界规则完善后并入）。

## 2. FreeWB（上游）数据文件

- `data/mb/default/wbzx.mb` / `pinyin.mb`：UTF-8 文本化码表，头部为「长度前缀 + UTF-8」元信息，
  记录为「编码 词条」行式（`MbDictionaryTable::loadFromStream` 解析）。
- `data/dict/freeime_chinese_dict.db`：与 10.8.9 词典字节一致。
- 用户词库：`data/user_word.txt`（文本）；自动造词：`data/autophrase.mb`；词频：`data/freq_*.dat`。

## 3. FreeIME 11 数据目录（`%APPDATA%\FreeIME11`）

```
data/mb/default/wbzx.mb        # 五笔码表
data/mb/default/pinyin.mb      # 拼音码表
data/user_word.txt             # 用户词库（文本，向上游格式兼容）
data/autophrase.mb             # 自动造词
data/freq_*.dat                # 词频
config.ini                     # UTF-8 配置（由旧 GBK INI 迁移而来）
```
